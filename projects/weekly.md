# Weekly

> 潮流周刊 source repo, a weekly curation of tech and lifestyle discoveries.

Website: https://weekly.tw93.fun

Weekly is an open source project by [Tw93](https://tw93.fun) with 870 GitHub stars. Source repository for 潮流周刊 (Trendy Weekly), a long-running weekly newsletter curating interesting tech discoveries, tools, and lifestyle content. Published continuously since 2021; the live issue count is in the RSS feed at weekly.tw93.fun.

## Key Features

- Published weekly without a gap since 2021
- Covers front-end, tools, AI, and lifestyle
- Published as a static site via GitHub Pages
