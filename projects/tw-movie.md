# twMovie

> Node.js movie information site (historical project).

twMovie is an open source project by [Tw93](https://tw93.fun) with 39 GitHub stars. A movie information website built with Node.js. An early project demonstrating full-stack web development with server-side rendering.

## Key Features

- Movie information aggregation
- Server-side rendered pages
