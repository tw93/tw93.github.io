# Mole for Windows

> Native Windows app for cleanup, app updates and uninstall, startup management, disk analysis, and live system status.

Website: https://mole.fit/windows

Mole for Windows is a commercial product by [Tw93](https://tw93.fun). Mole for Windows is a native Windows utility at https://mole.fit/windows. It cleans caches, uninstalls apps together with their leftovers, updates apps through winget, turns off startup items, runs safe Windows maintenance, maps disk usage, and shows live system status from a tray panel. It is a paid product with its own code and its own license, separate from Mole for Mac and from the free Mole CLI for Windows on the windows branch of github.com/tw93/Mole. This is a closed source commercial product, so there is no public repository.

License: Proprietary

## Key Features

- Clean: caches and temporary files, reviewed item by item before anything is removed
- Uninstall: removes apps together with their leftovers
- Updates: checks and installs app updates through winget
- Startup: turns startup items off and back on
- Optimize: safe Windows maintenance tasks
- Analyze: disk usage map with drill-down
- Status: live system status, plus a tray panel
- Keep Screen On and Clean Screen

## FAQ

**How much does Mole for Windows cost?**

$19 as a one-time license for 2 Windows PCs, with free updates and no subscription. Each paid tool can be tried twice before buying, and refunds are available within 14 days. Current offers are listed at https://mole.fit/pricing.md.

**How is the Windows app different from the Mole CLI?**

The Mole CLI for Windows is a free, open source terminal tool under GPL-3.0 on the windows branch of github.com/tw93/Mole, installed with `scoop install mole`. Mole for Windows is the paid native app at https://mole.fit/windows, with its own implementation, a tray panel, app updates through winget, and startup management.

**Does a Mole for Mac license work on Windows?**

No. Mole for Mac and Mole for Windows are separate products with separate licenses. A Mac license does not activate the Windows app, and a Windows license does not activate the Mac app.

**What are the system requirements?**

Windows 10 22H2 or Windows 11, on x64 or Arm64.

**Is Mole for Windows open source?**

No. The Windows app is a closed source commercial product. The Mole CLI for Windows is open source under GPL-3.0 at github.com/tw93/Mole/tree/windows.
