# 900Month

> Chrome extension visualizing life in months on a 900-cell grid.

900Month is an open source project by [Tw93](https://tw93.fun) with 19 GitHub stars. A Chrome extension that displays your remaining life as a grid of 900 months (approximately 75 years). A visual reminder of time's passage, inspired by the 'Your Life in Weeks' concept.

## Key Features

- Life visualization in 900 months
- Chrome new tab integration
