# CreateJS npm

> npm package wrapper for CreateJS library.

CreateJS npm is an open source project by [Tw93](https://tw93.fun) with 19 GitHub stars. Packaged version of the CreateJS library for npm, making it easy to install and use in modern JavaScript projects with module bundlers.

## Key Features

- npm-installable CreateJS
- Module bundler compatible
