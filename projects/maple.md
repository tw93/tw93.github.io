# Maple

> Chrome extensions for browsing with the bookmark bar hidden.

Maple is an open source project by [Tw93](https://tw93.fun) with 509 GitHub stars. Maple is a set of three Chrome extensions for browsing with the bookmark bar hidden. Maple Bookmarks opens your bookmarks with a shortcut and searches them as you type, Maple NewTab replaces the new-tab page so the bookmark bar stays hidden there too, and Maple Theme is a plain white browser theme.

## Key Features

- Maple Bookmarks: open and search bookmarks with a shortcut
- Maple NewTab: Renaissance art, Bing image, Weekly picture, or blank backgrounds
- Maple Theme: a plain white Chrome theme
