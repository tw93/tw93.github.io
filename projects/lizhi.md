# Lizhi

> Web music player dedicated to Li Zhi's music collection.

Lizhi is an open source project by [Tw93](https://tw93.fun) with 15 GitHub stars. A web-based music player built as a tribute to Chinese indie musician Li Zhi (李志). Features a clean playback interface for his discography.

## Key Features

- Li Zhi music collection
- Clean web playback interface
